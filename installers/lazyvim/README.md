# Neovim + LazyVim Installer

Simple installer for Neovim and LazyVim on Ubuntu.

## Installation

From the repo root:

```bash
cd installers/lazyvim
```

Make the script executable:

```bash
chmod +x install.sh
```

Run the script:

```bash
./install.sh
```

Then start Neovim:

```bash
nvim
```

If `nvim` is not found:

```bash
source ~/.bashrc
nvim
```
