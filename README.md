# Neovim + LazyVim Installer

Simple installer for Neovim and LazyVim on Ubuntu.

## Installation

Make the script executable:

```bash
chmod +x install-lazyvim.sh
```

Run the script:

```bash
./install-lazyvim.sh
```

Then start Neovim:

```bash
nvim
```

If `nvim` is not found:

```bash
source ~/.bashrc
nvim
```
